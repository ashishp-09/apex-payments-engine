## 🌟 Featured Project

### 💳 [apex-payments-engine](https://github.com/ashishp-09/apex-payments-engine)
> **Distributed Payments & Double-Entry Wallet Ledger Engine**

- 🛡️ **Zero-Drift Double-Entry Accounting:** Enforces $\sum \text{debits} - \sum \text{credits} = 0$ both at the application domain layer and via deferred PostgreSQL database triggers.
- 🔁 **Two-Tier Idempotency:** Sub-millisecond Redis fast-path distributed lock paired with PostgreSQL durable claims and cached response replay.
- ⚡ **Hold-Authorize-Settle Distributed Saga:** Decoupled network transaction boundaries isolating external Stripe / PSP I/O from database row locks.
- 📦 **Transactional Outbox:** Dual-write elimination using PostgreSQL `FOR UPDATE SKIP LOCKED` for reliable, asynchronous event streaming.
- 📊 **Observability & Load Tested:** Pre-configured Prometheus metrics and Grafana dashboards; tested for zero-oversell under concurrent write stress.
